# 服务器部署说明

## 服务器信息
- IP: 43.132.156.72
- 部署方式: Docker后端 + Nginx前端

## 步骤一：本地构建前端

在本地项目目录执行：
```bash
cd frontend
npm install
npm run build
```

## 步骤二：上传代码到服务器

将整个项目目录上传到服务器：
```bash
scp -r ./* user@43.132.156.72:/home/ubuntu/xinshi_system/
```

## 步骤三：数据库迁移（如需要）

1. 导出本地数据库（如未导出）：
```bash
pg_dump -U postgres -d xinshi_system > xinshi_system.sql
```

2. 上传到服务器：
```bash
scp xinshi_system.sql user@43.132.156.72:/tmp/
```

3. 服务器上启动数据库并导入：
```bash
cd ~/xinshi_system
docker-compose up -d postgres
docker exec -i xinshi_postgres psql -U postgres -d xinshi_system < /tmp/xinshi_system.sql
```

标注业务第三阶段发布前必须先备份，再执行迁移：

```bash
docker exec xinshi_postgres pg_dump -U postgres -Fc xinshi_system > backups/xinshi_system_before_annotation_phase3.dump
docker exec -i xinshi_postgres psql -v ON_ERROR_STOP=1 -U postgres -d xinshi_system < data/migrations/20260826_annotation_phase3.sql
docker exec -i xinshi_postgres psql -v ON_ERROR_STOP=1 -U postgres -d xinshi_system < data/migrations/20260827_annotation_account_library.sql
docker exec -i xinshi_postgres psql -v ON_ERROR_STOP=1 -U postgres -d xinshi_system < data/migrations/20260827_annotation_account_plaintext.sql
docker exec -i xinshi_postgres psql -v ON_ERROR_STOP=1 -U postgres -d xinshi_system < data/migrations/20260827_resource_person_locale_profile.sql
```

执行前应先确认 `annotation_project_assignee` 没有会与新四列唯一索引冲突的历史重复数据。
已经执行过账号资产库迁移的环境需补跑 `20260827_annotation_account_plaintext.sql` 和 `20260827_resource_person_locale_profile.sql`。如果旧账号表已有密文，明文化脚本会主动中止，必须先使用原密钥导出明文，不能直接丢弃历史数据。

## 步骤四：启动后端Docker

```bash
cd ~/xinshi_system
docker-compose up -d --build
```

## 步骤五：配置Nginx前端

1. 安装nginx：
```bash
sudo apt update
sudo apt install nginx
```

2. 复制前端构建产物到nginx目录：
```bash
sudo cp -r ~/xinshi_system/frontend/dist/* /var/www/html/
```

3. 配置nginx代理：
```bash
sudo cp ~/xinshi_system/nginx.conf /etc/nginx/sites-available/default
sudo systemctl restart nginx
```

## 常用命令

```bash
# Docker后端
cd ~/xinshi_system
docker-compose up -d          # 启动
docker-compose logs -f        # 查看日志
docker-compose restart        # 重启

# Nginx
sudo systemctl restart nginx  # 重启nginx
sudo nginx -t                # 检查配置
```

## 更新部署

如果代码有更新：

```bash
# 前端更新
cd ~/xinshi_system/frontend
npm run build
sudo cp -r dist/* /var/www/html/

# 后端更新
cd ~/xinshi_system
docker-compose build --no-cache
docker-compose up -d
```
