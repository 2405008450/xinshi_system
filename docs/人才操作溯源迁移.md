# 人才操作溯源字段

人才主档新增 `operated_by`、`operator_name`、`operated_at` 三个可空字段，分别保存最近操作用户 ID、姓名快照和操作时间。历史记录不回填。

新增、编辑、姓名修改、状态修改及招聘库共用档案写入由后端记录当前登录用户；资源开拓生成档案时记录实际保存用户。附件和系统同步不更新该信息。

## 发布顺序

先确认数据库连接目标并备份，再执行迁移，最后更新后端与前端。新增 ORM 字段依赖迁移完成，迁移前不得将修改后的代码同步到正在自动重载的后端。

迁移可重复执行，不随 API 启动自动运行。在本机 PC项目目录执行：

```powershell
$env:APP_ENV = 'development'
$env:LOCAL_SCHEMA_MIGRATIONS_ENABLED = 'true'
& '.\.venv\Scripts\python.exe' -m tools.migrate_talent_operation
Remove-Item Env:LOCAL_SCHEMA_MIGRATIONS_ENABLED
```

如果连接目标是生产数据库，须先取得明确迁移授权；局域网执行位置不代表数据库也是调试数据库。

前端保持原字段配置存储键：无配置时默认显示两个新增列，已有用户配置保留原选择；可在字段设置中启用新增列或恢复默认。
