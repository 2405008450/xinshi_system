# 标注项目云端资料管理

标注项目资料、报价单和合同各自支持多个文件，单文件上限为100 MiB（界面显示100MB）。上传新版明确指定文件ID，同名上传不覆盖。新版保留全部历史，取消编辑不改变正式文件。历史共享路径保留只读，笔译文件管理不变。

## 项目资料分级目录

“项目资料”是根目录，支持创建一级文件夹及一级文件夹下面的二级文件夹；根目录和两级目录都可以上传附件。已有资料默认保留在根目录，“报价单”“合同”不参与目录管理。本期只提供目录创建、浏览，不提供已保存目录改名、删除、文件移动或本地目录批量上传。

项目编辑中的“新建一级文件夹”“新建二级文件夹”先创建待保存目录。二级必须选择一级父目录，默认使用当前一级目录或当前二级目录的父目录；没有一级目录时不能创建二级。目录和附件在项目保存事务中一起生效，取消编辑不改变正式资料；保存失败保留待保存内容供重试。上传文件绑定选择文件时的目录，切换目录不改变归属，上传新版保留原文件目录。

目录名称去除首尾空白后为1～100字符，不能包含控制字符、斜杠或反斜杠，不能使用`.`或`..`。同项目同父目录下不允许同名，不同父目录允许同名。目录只表示数据库中的业务关联，物理文件仍使用随机存储键，不拼接用户输入路径。

公共资料组件在编辑表单、列表资料浮层及详情小窗中统一显示目录树和当前目录文件，窄屏改为上下排列。只读界面仅浏览、下载及查看历史。复制母订单资料到子订单时复制全部目录（含空目录），为子订单生成独立目录ID并重新映射附件归属，文件内容仍复用不可变上传对象。

### 资源管理器式交互

项目资料使用顶部工具栏、路径栏、左侧目录树和右侧详细列表。列表按“名称、修改时间、类型、大小”展示当前目录的直属子文件夹和文件，文件夹在前；底部显示目录及文件数量和选中项信息。单击选中，双击文件夹进入、双击已保存文件下载；选中文件后可在工具栏下载、查看历史、上传新版或移除，也可使用右键菜单或行末“更多操作”。文件移除仍需确认并随项目保存生效。

路径栏可以直接返回任意祖先目录，提供后退、前进和返回上一级按钮。文件列表支持上下方向键选择、Enter打开，以及Alt+左/右/上箭头导航；切换目录后保留列表区键盘焦点。编辑状态支持把多个文件拖到当前目录上传，沿用100MB限制、上传进度、失败重试和暂存机制；不支持拖放整个本地文件夹。只读界面禁止上传和修改。窄屏目录树默认收起，可通过路径栏的“目录树”按钮展开；工具栏使用“新建”菜单选择目录层级，文件低频操作收进“更多”，隐藏低频列，项目表单底部操作栏保持固定。

## 数据与接口

独立使用 `annotation_material_upload/folder/file/version/deletion` 五张表。目录按项目隔离，逻辑文件的可空`folder_id`表示所属目录，空值表示根目录。上传记录在关联前为暂存，24小时过期；关联后作为不可变版本内容记录。删除队列与项目变更同事务提交，只有云端清理进程删除物理文件并重试失败项。

接口前缀为 `/api/projects/annotation`：

- `POST /material-uploads`：单文件multipart上传，返回暂存ID、原名称、大小、SHA-256、上传人及UTC时间。
- `DELETE /material-uploads/{id}`：取消自己的暂存，已关联文件不受影响。
- `GET /{project_id}/materials`：三类资料的最新版本。
- `GET /{project_id}/material-folders`：项目目录列表，返回`id`、`parent_id`、`name`、`created_at`，前端构建两级目录树。
- `GET /{project_id}/materials/{file_id}/versions`：历史版本。
- `GET /{project_id}/materials/{file_id}/versions/{version_id}/download`：鉴权下载，强制附件响应。
- 项目新增/编辑增加 `material_changes`，包含 `additions: [{upload_id, category, file_id?, folder_id?}]`、`removed_file_ids`及`created_folders: [{id, parent_id?, name}]`。category为project、quotation、contract，只有project允许关联目录。目录ID由前端生成UUID，同次保存允许先创建父子目录再关联附件。每次保存最多创建200个目录。编辑必须携带 `expected_updated_at`。省略变更参数不修改资料，旧请求省略目录字段仍兼容；旧客户端上传新版也保留文件已有目录。资料列表和版本响应增加`folder_id`，原响应结构及下载接口不变。

移除文件会移除全部版本，不提供回收站。附件不会自动加入业务邮件。文件不执行、不解压，不提供预览或匿名公开链接。

## 发布配置（本次不执行生产发布）

1. 备份数据库，执行 `data/migrations/20261013_annotation_materials.sql`；已有显式全量迁移入口也会创建新表。服务启动不自动迁移。
   分级目录升级另外执行`data/migrations/20261016_annotation_material_folders.sql`，可重复执行，保留原文件及版本；已支持子订单资料复制的环境应具备`20261015_annotation_material_shared_versions.sql`对应结构。显式全量迁移入口同步接入目录迁移，先完成数据库升级再启动新版本。
2. 云端配置 `ANNOTATION_MATERIAL_STORAGE_MODE=local`，使用独立持久化卷 `annotation_materials`，路径 `/app/data/annotation_materials`。默认disabled，完成迁移前不启用。
3. 局域网配置 `ANNOTATION_MATERIAL_STORAGE_MODE=remote`、`ANNOTATION_MATERIAL_REMOTE_ORIGIN=https://oa.xinshify.com.cn`。两端必须使用同一业务数据库、用户身份及兼容的签名配置；只在受保护运维渠道配置密钥，不把凭据放入仓库。
4. 发布两层Nginx配置：资料接口请求体110MiB、读写超时300秒，关闭代理请求/响应缓冲。局域网额外反向代理如存在，也需要相同限制。后端仍按实际文件字节限制100MiB。
5. 云端每分钟清理过期暂存及删除队列；失败保留attempts和last_error，日志输出失败重试。存储不可用时请求明确失败，remote模式绝不降级为本地长期存储。
6. 正式切换前核对云端/局域网相同项目、互认令牌、上传下载校验摘要以及文件只落云端。上游401转换为502提示配置问题，避免退出局域网用户登录。

按项目环境规范在本机已登录桌面会话启动或重启后端；核对后端与 explorer 的 SessionId，并在同一交互式上下文只读枚举实际 UNC 目录。非桌面上下文须检查并使用本机 XinshiDebugBackendInteractive，不能回退到 Session 0。

## 备份与回滚

数据库备份必须包含五张资料表，文件备份必须包含独立资料卷。备份窗口暂停资料写入与清理，取得配套的数据库和卷快照，并记录时间及文件SHA-256；恢复到隔离环境抽检最新版和历史版下载。仅数据库备份不能恢复文件。

回滚时先暂停资料写入，恢复应用版本并保留新表与资料卷；不能删除卷或把新上传资料视作共享路径文件。正式数据校验完成前不执行破坏性回滚。
