# 笔译项目文件字数统计

入口：笔译项目的“字数统计”小窗 → “选择文件／UNC 共享路径自动统计”。项目表单内的字数矩阵也提供相同工具。
统计模块已内置于 xinshi_system，不再调用 fastapi-llm-demo 或 AI_translation_system12312 服务。

## 使用

1. 选择本机文件，或输入允许访问的 UNC 共享路径，读取列表并勾选文件。
2. 根据报价范围选择是否包含 Excel 隐藏内容，以及备注、页眉页脚等额外内容。
3. 开始统计，查看逐文件状态及总量。图片型文件提示需 OCR；失败文件不按零字通过。
4. 全部成功后，选择“预统计”或“我司统计”，选择字数或不计空格字符数后回填。
5. 回填只更新当前统计草稿；仍需保存统计或项目。客户统计不会被自动覆盖，替换已有行会先确认。

每批最多 50 份文件，单文件最多 50 MB，每批合计最多 200 MB。统计任务按登录用户隔离，单文件解析超过 90 秒会明确失败。
DOCX/XLSX/PPTX/TXT/PDF 可直接读取。DOC/XLS/PPT 需要完整 LibreOffice，可配置 LIBREOFFICE_PATH；缺少依赖时明确提示先另存为新格式。
不包含自动 OCR，不调用外部 AI。扫描文件必须先完成 OCR，再进行报价统计。

## 运行与 UNC 权限

使用根目录 .venv 和 deploy/start_local.ps1，先执行 -CheckOnly，再按现有方式启动 Backend。
服务必须位于已登录桌面会话，继承 SMB 凭据。OPENPATH_ALLOWED_ROOTS 使用分号分隔企业允许根目录；沿用 docs/infra.md 已确认的两处 Win-server 共享目录。
UNC 列表只读，不修改共享文件；拒绝本地服务器任意路径、路径穿越、符号链接及目录联接。
不支持云端应用自动访问本机局域网 UNC。若后续部署云端，仍需该运行主机具备共享目录连通性与权限。

## 统计口径与验收

迁移自 fastapi-llm-demo 已验收的 text-content-v4-hidden-scope 文件提取规则与纯文本计数核心，本项目版本标识 file-text-v4-local-1。
保留 DOCX 自动编号和明确韩文语言标记、PPT 合并单元格兼容计数、Excel 隐藏行列及工作表规则。与近期 AI 项目“仅解析翻译句段”的范围不同，报告按本工具勾选范围执行。

只读真实样本回归：tools/verify_document_word_count_samples.py，结果 artifacts/document-word-count/samples.json。
32 份样本（DOCX 12、XLSX 10、PPTX 10）与迁移前留存主字数完全一致；不将“两套实现一致”扩展为所有文档相对 Word/WPS 均无误差的承诺。
后端隔离测试：.venv/Scripts/python.exe -m pytest tests/test_document_word_counts.py -q。
界面隔离测试：.venv/Scripts/python.exe tools/verify_document_word_count_ui.py，挂载真实组件、模拟业务 API，不写生产数据。
UNC 实际只读枚举、勾选与统计已在本机交互式会话验证，摘要 artifacts/document-word-count/unc.json。

任务与结果保存在单个后端进程内存中，完成一小时后清理；上传临时文件在任务结束后删除。重启服务后未保存结果需重新统计；当前入口应使用单个后端 worker。
本次不涉及数据库迁移或云端发布。
