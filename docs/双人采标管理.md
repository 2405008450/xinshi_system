# 双人采标管理

双人采标工作区在标注项目订单的操作菜单中打开，支持母订单、子订单及三级订单。订单执行数据独立维护，不随订单复制或上级字段继承自动复制。

## 使用流程

1. 将订单设置为“双人采标”，首次打开时建立工作区。有读取权限但没有编辑权限的用户不会触发初始化。
2. 在项目联系中筛选、引用已登记人才，或新增人才及搭档。按人才ID去重，只合并来源，不重置已维护的参与意愿；复制资料不会登记为已联系。联系方式沿用人才库的权限和脱敏规则。
3. 联系资料独立维护项目意愿、报价、可工作时间、具体公司账号或群的渠道状态。“尚未联系、没回复、已回复”与参与意愿分开；登记跟进时选择回复情况，由服务端记录操作人及时间，业务联系日期允许补录。口音按人才语言保存，可在联系编辑中单独同步到人才总库。
4. 分组由两人组成，默认禁止同一人才出现在当前订单多个有效组。换人需要原因并生成成员版本；新批次使用新版本，旧批次保持原成员。
5. 每组自动建立首批采集任务，可以增加命名批次。部分任务转标注前，先将需要转入的范围作为独立批次描述，选择这些批次转入；重复转入返回已有任务。
6. 标注可以分配给其他人员，与采集并行。培训和试采/试标不是开工前置条件。过程记录分别维护价格调整、培训、试采/试标与考核、进度节点、质检、返修、账号引用和人员表现。

价格、个人价格、工作量、进度描述均为自由文本，不自动均分或结算。时间字段明确按UTC+8输入、存储和展示；耗时按实际时间差计算，人工调整需填写原因。新增及修改记录保留审计快照，插入节点只调整显示序号，不改变已有节点ID。

平台与账号仍在既有账号管理中维护，支持平台第二链接。工作区只保存账号资产引用，不复制密码；所引用账号必须当前分配给该订单的任务人员。换人后需在账号管理中完成释放与重新分配。

已有执行记录的分组或任务应退出或归档，不能物理删除。工作区存在时禁止直接删除订单，避免历史审计随订单丢失。取消订单的双人采标类型前需归档工作区；归档历史入口仍保留，恢复编辑前需恢复订单类型。

## 数据与接口

接口前缀为 `/annotation-ops/projects/{project_id}/paired-workspace`。包含初始化、设置、联系人、人才引用及新增、分组、任务、转入、过程记录、附件与历史查询。读取不创建数据，写入使用订单行锁、事务和修订号校验；建组、任务及记录新增使用请求标识和内容摘要，转入按来源批次保持唯一。

工作区沿用项目读写权限；新增人才、修改口音和账号引用同时检查对应权限。新建人才复用现有查重机制，并与加入联系表在同一事务保存。采集与标注评价归入实际人员的项目经历，不覆盖人才总体评分。任务历次参与人员通过独立关联表保存外键，避免换人后历史人员被误删。

资源开拓新增提示依据实际“已添加”的业务日期，自工作区建立当日起统计。同日同人才去重，保留渠道来源；缺失业务日期的历史记录不推断。群登记人数与可识别人才分别展示，群人数保留未去重人次口径，不获取外部群成员。

## 增量迁移与验收

迁移文件为 `data/migrations/20261024_annotation_paired_workspace.sql`，创建采标业务表，增加语言口音、平台第二链接，并扩展考核状态约束。可重复执行，不转换历史音频采集类型，不回填执行记录，不在服务启动时执行。

当前代码交付不包含业务库迁移、常驻服务重启或生产发布。在获授权的发布窗口，须先按根目录AGENTS.md核对主机、项目目录、Git提交、数据库并备份，再在目标库执行迁移，随后更新运行代码。

在本机使用项目 `.venv` 执行：

```powershell
& '.\.venv\Scripts\python.exe' tools/verify_annotation_paired_postgres.py
Push-Location frontend
node node_modules/vite/bin/vite.js build --outDir ../.tmp/paired-build
Pop-Location
& '.\.venv\Scripts\python.exe' tools/verify_annotation_paired_ui.py
```

前端构建应在 `frontend` 目录运行 `node node_modules/vite/bin/vite.js build --outDir ../.tmp/paired-build`。浏览器验收脚本读取该隔离构建，全部API拦截为内存数据；PostgreSQL脚本建立本机临时实例，不连接业务库。结果及截图保存在 `.tmp/annotation-paired-postgres` 和 `.tmp/paired-ui`。

首版不提供自动发消息、拨号、自动读取群成员、自动推荐质检员、进度偏差通知或自动对账。
