# 会话分组、分类与资源讨论

聊天侧栏采用可折叠分组与带数量的二级分类，以缩进、细线和选中态表示层级，不再使用文件夹图标。移除会话总数文字、旧状态按钮区、顶部及左侧主题入口，保留群聊、单聊和 @我。

默认一级分组：资源开拓讨论、标注项目、笔译项目、口译项目、招聘项目。标注项目的二级分类来自当前业务状态，状态变化后自动归类。二级分类右侧数量按当前用户可访问的会话去重计算，不计私聊，也不受当前关键词和未读快捷条件影响。自定义一级分组与二级分类沿用团队分类数据，原有的一层分类继续作为一级分组保留。

分组区域底部手柄支持上下拖动调整高度，键盘方向键也可调节；区域内部可滚动。一级分组与同一父级下的二级分类支持拖动排序，不改变层级或会话归属；高度和顺序按当前账号保存在本机浏览器。管理员可移除自定义分组，采用停用方式，保留对话与消息。重复的“口译项目群”已按用户指令移除，保留“口译项目”。

会话搜索先按当前分组限定范围，再按名称、订单号、最近消息及发言人执行多关键词包含匹配；点击“全部分组”解除分组限制。输入框提示随当前范围更新，搜索词在切换分组时保留；清空关键词只恢复当前范围的会话。群聊、单聊、@我及置顶/未读等快捷条件继续生效，不超出当前账号原有访问权限。

拥有项目读取权限的用户可右键“标注项目”（或聚焦后按 Shift+F10），打开“标注项目管理 · 加入会话”可拖动弹窗。弹窗复用原项目管理列表的关键词搜索、查询/重置、高级筛选、列筛选、字段设置、表格和完整分页，隐藏独立“详情”列，操作列显示“加入会话”，已有关注显示“已加入”。子订单展开也沿用同一模式。点击加入先重新读取项目状态，再通过既有关注接口加入当前账号的会话列表，自动定位到相应状态分类并清空会话搜索；后续状态变化继续自动归类。弹窗允许连续加入，完成后关闭；不改写项目状态或手工维护分类关系，也不依赖二级分类表迁移。

资源开拓讨论下的六项为独立会话：平台讨论、资源讨论、企微管理、发布需求、高校渠道、其他渠道。它们出现在分组下方的会话列表中，可点击进入消息区，不再出现在二级分类树或设置分类选项中。超级管理员和 Jimmy 在资源分组下新建的项目也作为独立讨论会话。

## 权限和消息

分组、分类及新讨论的新增和维护只允许活动账号 Jimmy（按真实登录账号名校验）和超级管理员。讨论会话的访问沿用资源开拓模块的权限范围：talents:read/write、translators:read/write、resource_development:delegate 任一，或超级管理员、Jimmy。普通用户不能通过修改显示名获得管理权限。

讨论消息独立于笔译群、标注群、私聊以及原消息主题数据。支持纯文本收发、引用、历史分页、搜索、未读、置顶、特别关注、本人24小时内撤回和超级管理员撤回。相同客户端请求标识的重试不会重复发送。原有主题消息保留原来源和访问边界，不会被自动搬进新讨论会话。讨论功能当前不提供附件与 @ 通知。

讨论消息以带时区字段存储，时间生成沿用业务 UTC+8，接口明确输出 +08:00，前端复用业务时间展示工具；不修正历史时间。

## 数据结构与迁移

- data/migrations/20261020_chat_session_folders.sql：新增 chat_session_category_folder 及父级索引，保存自定义分类的层级。
- data/migrations/20261020_resource_discussion_rooms.sql：新增 chat_discussion_message 与 chat_discussion_member，分别保存讨论消息和个人阅读/置顶/关注状态。

两个脚本只创建新表和索引，不改写原项目、主题、分类、消息或私聊，不在启动时自动执行。默认分组和讨论使用 data/chat_session_folders.json 中稳定的 UUID；读取默认目录不会写入种子数据。尚未迁移时可查看默认分组、状态分类数量和六个讨论入口，但讨论收发与新增二级分类会明确提示未启用，不能视为功能已经完整启用。

当前连接云端业务数据库，执行结构迁移必须按 AGENTS.md 与 docs/infra.md 获得单独明确授权，核对主机、目录、Git 提交、数据库目标与备份。开发及本机重启不授权云端迁移。回退应用可保留新表；已有聊天记录后不能直接删表。

聊天能力探测、主题表、分类表和资源讨论表的只读结构检查必须复用当前 `Session.connection()`，不得在认证查询已持有连接时通过 `inspect(engine)` 再申请额外连接，避免并发请求占满连接池后互相等待。第一阶段能力缓存仍按 Engine 隔离；`tests/test_chat_schema_connections.py` 使用临时 SQLite 和满载的 1/4 条连接验证此边界，不连接业务数据库。

通知 WebSocket 的初次认证、未读快照、心跳重新认证和项目订阅鉴权须通过线程池执行同步数据库工作，在线程内创建并关闭 Session，只向事件循环返回标量快照。不得在异步收包循环中直接等待同步数据库或连接池，否则会阻塞 HTTP 响应及请求清理。`tests/test_notification_ws_database.py` 验证线程隔离、连接释放与订阅权限。大屏右上角“×”关闭当前会话；关闭最后一个会话后退出大屏，不产生最小化任务；“－”只最小化，保留会话。
