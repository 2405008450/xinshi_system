# Windows 本地截图桌面入口

先按项目规定启动 localhost 服务，然后双击本目录的 `start-desktop.bat`。
首次启动通过 npm 安装固定版本的 Electron；需要本机 Node.js 和网络连接。
桌面入口中需重新登录原账号，业务仍连接同一本地系统。

点击顶部“截图”或按默认 Alt+A，直接截取鼠标所在显示器的整个屏幕，不弹出浏览器的屏幕选择框。
支持框选、方框、圆框、箭头、画笔、马赛克、文字、表情、撤销、下载和复制。
此入口仅在桌面窗口获得焦点时响应快捷键，不注册操作系统全局热键。
截图只交给当前页面编辑，不自动上传。

普通浏览器仍按浏览器要求选择屏幕。文字识别、翻译、自动滚动长截图与系统级置顶贴图尚未实现；网页“贴图”为系统页面内的可拖动预览。
本入口不启动、部署、迁移或维护数据库，也不开放供其他网页访问的截图 HTTP 服务。
